# CombatFusion · 8 周进度清单

> 每天开工前找到当天的行，做完把 `[ ]` 改成 `[x]`。
> 掉队了就按下面的优先级砍：**P2 → P1 → P0，永远先砍功能、不砍演示闭环。**

## 砍功能优先级

| 优先级 | 内容 | 说明 |
| --- | --- | --- |
| **P0 不能砍** | 双开联机跑通 / 手写 FSM / 手写行为树 / 对象池 + 真实对比数字 / 能打死人 | 少了任何一个项目就不成立 |
| **P1 尽量保** | Excel 配置流水线 / 背包 MVC / 第一三人称切换 / 性能报告 / README 三张图 | 少了显得只会写功能不会做工程 |
| **P2 可以砍** | 闪避 / 弹孔累积 / 伤害数字 / 屏幕震动 / 顿帧 / 断线重连 / 第二种弹道模式 | 只影响观感 |

## 如果只剩四周

1. 清理仓库 + 输入抽象 + 相机 + 移动 + 状态机三态
2. 近战 + 受击死亡 + 行为树（追击/巡逻两分支）+ 敌人血量
3. 对象池 + 射击 + 命中判定 + F1/F2 对比 + 一组数字
4. Mirror 主角同步 + 敌人上服务器 + CmdShoot/Rpc + README + 视频
